## 使った時間

### PC作業

主にChatGPTとのやりとりや、Astro、GitHub、Cloudflareでの実装・設定作業などで、合計43時間程度。

| 曜日         | 作業時間/日 | 日数 | 時間 |
| ------------ | ----------: | ---: | ---: |
| 平日         |          1h | 21日 |  21h |
| 土・日・祝日 |          2h | 11日 |  22h |
|              |             |   計 |  43h |

### 考える時間

PCでの作業とは別に、移動中、食事中やお酒を飲んでいるときなど、技術のことやコンテンツについて考えたり、推敲したりする時間がかなりあった。体感では、PC作業と同じくらい、あるいはそれ以上だったと思う。

PC作業と考える時間を合わせると、この約1ヶ月で費やした時間は約86時間だったと思う。

## 要素別の割合

ここまでやったことの要素別の割合は以下のような感じ。圧倒的に自分でコンテンツを考える時間が多い。それ以外は、AI（主にChatGPT）に相談し、内容を確認して問題なければ採用するという進め方がほとんどだった。

| 要素          | 割合 | 自分:AI |
| ------------- | ---: | :-----: |
| コンテンツ    |    6 |   7:3   |
| 実装・開発    |    1 |   1:9   |
| UI/UXデザイン |    1 |   1:9   |
| インフラ      |    1 |   1:9   |
| 運用          |    1 |   1:9   |

これでウェブサイトとしてのベースはできた。これからは運用しながら改善や実験を重ね、その過程もこのサイトに記録していく予定。
